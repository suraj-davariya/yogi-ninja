## 🤖 Futuristic AI & MCP Integration

Yogi Ninja is built **by AI, for AI**. The architecture is optimized for Model Context Protocol (MCP) and autonomous agent collaboration:

### ⚡ Autonomous Execution Pipeline
The platform operates a self-sustaining data lifecycle:
1.  **Discovery**: Daily cron-triggered scraping of the global artisan community.
2.  **Synthesis**: Hardened Python engine transforms metric data into artisan-grade culinary volumes.
3.  **Filtration**: Real-time safety audit against the **Prenatal Safety Protocol** (zero stabilizers, zero alcohol).
4.  **Deployment**: Automated GitHub Actions commit new valid recipes directly to the application state.

### 🧠 Model Context Protocol (MCP) Readability
This repository is structured for effortless ingestion by other bots and MCP servers:
*   **Structured Metadata**: Every recipe in `web/src/data/recipes.json` follows a strict, type-safe schema.
*   **Skill Matrix**: Historical intelligence is persisted in the `skills/` directory, allowing new agents to inherit the context of every technical milestone.
*   **Orchestration Docs**: The `agents/` folder contains high-density context headers for instant agent boot-up.

## 🛡️ Prenatal Safety Standard (Non-Negotiable)

Every formulation in the Yogi Ninja index must pass a zero-tolerance safety audit:

*   **❌ PROHIBITED**: Raw eggs, alcohol, industrial stabilizers (CMC, GMS, Xanthan), and artificial sweeteners (Erythritol, Xylitol).
*   **✅ APPROVED**: Pasteurized dairy, plant milks (oat, coconut), ripe bananas, mild fruits, and medjool dates.
*   **🍯 SWEETENERS**: Minimal amounts of pure maple syrup or artisan honey only.
