**CONSTRAINTS**

1. Initialize the Next.js project and create the `progress_checklist.md` file.

4. Build the Recipe Card component. This must include exact pint measurements, freezing time, spin settings (like Sorbet or Lite Ice Cream), and respin fixes.
5. Include a persistent disclaimer component reminding the user to confirm unusual ingredients with her healthcare provider.

**OUTPUT FORMAT**
Output production ready React code using Tailwind CSS for styling. Ensure all components are modular. Provide a final summary of the completed batch when finished.

**VALIDATION**
Before completing your turn, verify that the `progress_checklist.md` is updated. Verify that no prohibited ingredients exist in your mock data. Ensure all recipes specify smooth textures and small portions for easy digestion.
