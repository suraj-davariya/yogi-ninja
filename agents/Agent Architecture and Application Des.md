# Agent Architecture and Application Design

## Overview
The application relies on a coordinated team of expert professional agents. Each agent handles a specific domain of the web application development and recipe formulation process.

## The Expert Agent Team

### 1. Executive Orchestrator
This agent manages the overall workflow. It tracks the batch progress of recipe creation and updates the system state after every completed task. It ensures all other agents meet the required quality standards before showing results to the user.

### 2. Formulation Scientist
This agent crafts the actual recipes. It focuses on simple ingredients like pasteurized milk, plant milk, yogurt, bananas, mild fruit, and oats. It uses small amounts of natural sweeteners. It prioritizes calm flavors, small portions, and perfectly smooth textures.

### 3. UI and UX Designer
This agent oversees the frontend user experience. It ensures the interface remains elegant and intuitive. It manages the tagging system layout and the visual display of the batch tracking progress.

### 4. Quality Assurance Reviewer
This agent validates every recipe against strict pregnancy safety guidelines. It anticipates potential culinary failures and ensures respin instructions are always included. It actively blocks any unauthorized ingredients.
